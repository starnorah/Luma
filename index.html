Big O Notation Cheat Sheet

  • O(1) - Constant Time: Array lookups, Hash table inserts.
  • O(log n) - Logarithmic Time: Binary Search.
  • O(n) - Linear Time: Iterating through an array.
  • O(n log n) - Linearithmic: Merge Sort, Quick Sort.
  • O(n^2) - Quadratic: Bubble Sort, Nested loops.

Dijkstra's Algorithm Summary

Used for finding the shortest paths between nodes in a graph. It iteratively selects the unvisited node with the lowest distance, calculates the distance through it to each unvisited neighbor, and updates the neighbor's distance if smaller.
